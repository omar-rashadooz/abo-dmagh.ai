📖 Overview

Abo-Dmagh.ai is an independent AI research and experimentation project dedicated to building small language models from scratch.

The project explores the fundamentals of artificial intelligence, neural networks, and language modeling through hands-on development and experimentation.

Instead of relying entirely on pretrained models or existing AI solutions, Abo-Dmagh.ai focuses on understanding the process behind building a language model — from designing its architecture and preparing datasets to implementing training pipelines.

The main objective is to experiment with different model sizes, explore training strategies, and continuously improve the understanding of how language models work.

🎯 Project Goals

- 🧠 Build from Scratch: Develop language models and experiment with neural network architectures.
- 📚 Dataset Engineering: Prepare and organize datasets for language model training.
- ⚙️ Model Scaling: Explore different model sizes and parameter configurations.
- 🔬 Experimentation: Test different training strategies and model configurations.
- 💻 Accessibility: Explore techniques that can work with limited computational resources.
- 🚀 Continuous Learning: Understand, improve, and document the process of building AI systems.

🧠 Model Versions

Abo-Dmagh.ai explores language models at different parameter scales.

Model| Parameters
1M| 1,000,000
16M| 16,000,000

Each version represents a different model scale and an opportunity to experiment with neural network architecture, training strategies, and language modeling.

The repository focuses on sharing model-building code and experimentation rather than providing pretrained models or benchmark claims.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/omar-rashadooz/abo-dmagh.ai.git

2. Enter the Project Directory

cd abo-dmagh.ai

3. Set Up Python Environment

python3 -m venv .venv

Activate the environment:

Linux:

source .venv/bin/activate

Windows:

.venv\Scripts\activate

4. Install Dependencies

Install the dependencies required by the selected model implementation.

For example:

pip install torch numpy

5. Explore the Models

Choose a model directory:

cd 1m

Or:

cd 16m

Explore the source code, model architecture, dataset preparation, and training implementation.

Follow the instructions and dependencies associated with the selected version.

🔬 Development Philosophy

Abo-Dmagh.ai follows a simple philosophy:

Understand the technology by building it.

The project prioritizes:

- Understanding the mathematics behind neural networks.
- Writing and experimenting with model architectures.
- Exploring how datasets influence language models.
- Understanding the relationship between parameter count and model capacity.
- Learning through implementation rather than treating AI as a black box.

Every experiment is an opportunity to understand something new.

⚠️ Project Scope

Abo-Dmagh.ai is an experimental development project.

The repository primarily shares model-building implementations and experimentation code.

It does not claim that every model version is pretrained, production-ready, or capable of competing with large commercial language models.

The actual capabilities of each model depend on its architecture, training data, and training configuration.
